# Fishcasting

[![powered by hexdoc](https://img.shields.io/endpoint?url=https://hexxy.media/api/v0/badge/hexdoc?label=1)](https://github.com/hexdoc-dev/hexdoc)

Fishcasting addon for Hex Casting and Tide 2

This mod adds a small range of interoperability features between Hex Casting and Tide 2, as well as a few quality of life features.

Still quite early in development but if I have not made any mistakes, it should be playable. I want to publish via github actions but don't know how to. The wiki now works.
<details>

<summary>Some of the features this addon includes are</summary>

- Patterns for manipulating or reading the states of bobbers and fish

- Crystal Fishing Rod cost changed to Charged Amethyst

- Amethyst Bobber cost changed to include Crystalline Carp and be closer to a Focus

- Amethyst Bobber now a Focus Bobber

- Focus Bobbers which act as IotaHolderItems, executing the stored iota on reel.

- Unlucky Bait which prevents fish from ever biting

- Loud Line which prevents certain mobs from attacking you when line is cast

- Hookless Hook which prevents your thrown bobber from getting caught on entities

- Tacklebox Chair which automatically buckets, or otherwise takes a seated player's recently caught fish into its own inventory. (It's nice!)

- Message in a Bottle left by fishers long gone. Contains some random junk and some random tresaure! It is quite rare and won't be the easiest way to progress, but at least it will be an option. Found in warm ocean biomes.

- Royalty-Free Music Disc added, "Returning To The Surface" by "cookies+policy" on freesound.org

- Some new fish added, intended to be fun and cool and aid in pointing a player in the right direction for progressing. (If I was good enough to properly hint the player in the right direction...)

- Wandering Trader variant added for fishing. Functions as an alternate route for progression. Also intended to provide user with items not normally accessible in a void world, or a world devoid of certain resources.

- Another casting rod as an upgrade to the Crystal Casting Rod, without durability

- Various recipe additions and changes, intended to allow for more routes of progression without invalidating the current progression.

- And more!
